Model Formulation and Limitations

What does this model compute?

This prototype uses equation-compatible implementations of the GeoGeek water-optics forward model (IOPs to Rrs), first-order atmospheric forward model, matched-model atmospheric correction, and nominal rectangular spectral response functions.

400–700 nm · 1 nm
Gordon/GIOP parameterization and Lee interface approximation · Optically deep water
Single-scattering Rayleigh and aerosol path terms with two-way direct transmittance
Nominal rectangular bands; measured SRFs are not applied
Offline Float32 representation; not bitwise identical to upstream decimal tables
Implementation regression tested; no independent field validation

Scientific Limitations

  • ρTOA* is an idealized TOA reflectance proxy, not satellite-measured TOA radiance.
  • Gas absorption, multiple scattering, adjacency effects, sun glint, surface BRDF, and shallow-water bottom effects are excluded.
  • Forward and inverse calculations use the same first-order model. Numerical closure does not establish atmospheric correction accuracy.
  • The CDOM slope Sg = 0.0176 nm⁻¹ and NAP slope S_NAP = 0.0123 nm⁻¹ are fixed. The particle backscattering exponent η is adjustable within the original model bounds.
  • Source modules include upstream Git blob hashes. Float32 coefficient tables introduce small numerical differences.

Interaction Guide

Select a workspace from the top navigation. The Sensitivity workspace computes finite-difference local parameter responses and nominal sensor-band averages; it does not estimate measurement uncertainty, sensor noise, or inverse identifiability. Switch spectral quantities above the chart. Enter parameters numerically or with sliders. Use the wavelength probe, save A/B scenarios, import a compatible experiment JSON, or export CSV/JSON results. The Y-axis lock applies only to the active plot.
