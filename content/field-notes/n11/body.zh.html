你有没有这种感觉：学一个领域，缺的不是资料，而是一个能让你“开窍”的人。

我想很多人和我一样。学 线性代数，靠Gilbert Strang。 学AI，靠Andrew Ng。 而在GIS和遥感的学习路上，让我有同样感觉的人，就是Qiusheng Wu（吴秋生）。

图1 | 左一为Qiushe ng Wu 。 2025年，Wu因主导“开放科学研讨会暨论坛”（Open Science Workshop and Symposium）获得田纳西大学图书馆合作伙伴奖（UT Libraries Partner Award）。该奖旨在表彰校内外为提升图书馆服务可见度、促进开放获取与数据共享做出突出贡献的个人。Wu在获奖感言中表示：“开放科学的核心，是让知识成为可以共享的起点。”图片来源：https://x.com/giswqs/status/1930272240043458744 。

你可能没有听过他的名字，但你一定用过他写的开源库 —— geemap、leafmap、segment-geospatial 。 Wu 现任美国田纳西大学诺克斯维尔分校地理与可持续发展系 Associate Professor ，长期做 geospatial data science、remote sensing 和 open-source software development。 那些让你在Google Earth Engine里轻松处理遥感影像的Python库，那些让交互式地图变得像写Markdown一样简单的工具，很多都出自他的手笔。Wu慷慨地 把所有代码都放在了GitHub上，给所有人免费使用和分享。

图2 | Wu 开发并维护的开源项目（geemap、leafmap、samgeo、geoai） 。这四个开源库覆盖了从云端遥感数据交互（geemap）、交互式地图可视化（leafmap）、遥感影像智能分割（samgeo）到地理空间人工智能（geoai）的核心工作流。它们全部开源、免费，已在全球地理空间社区中被广泛使用，成为许多研究者与学生日常工作中的基础设施。

Make knowledge freely available to everyone 。 Wu正是这一理念的践行者。 他不仅持续开发和维护 open-source geospatial tools，还把 tutorials、documentation、example code 和 course materials 系统地公开在线，并长期在 GitHub Discussions 等社区中亲自回答使用者的问题 。 正因如此，Wu于2025年获得了Spatial Impact Award，并被认为是地理空间领域最高产的开源贡献者之一。从本科刚接触GIS时起， Wu 就一直是我 aspire to become 的那种人 。他让我看到，一份学术工作真正的分量，不只看它发表了什么，而要看它留下了什么。在发表观点、提出方法和完成论文之外，更重要的是， 把知识做成可以被传播、被复现、被不断完善的东西 。 代码可以被运行，方法可以被验证，资料可以被学习，工具可以被继承。Wu所做的事情便是如此：把个人的能力，转化为后来者的起点。

现在，他做了一个新平台，叫 OpenGeoPub 。没有花哨的商业模式，没有烦人的订阅制，只是 把面向地理空间学习的书籍、视频课程和 bundle 整合在一起。 平台第一个系列就是 《The Open Geospatial Python Series》 ，从基础编程到空间大数据，再到GeoAI， 每一本 都配上真实数据集和可复现代码。并且P ay what you want，Lifetime access。
