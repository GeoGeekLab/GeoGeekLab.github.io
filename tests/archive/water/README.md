# Historical Water browser tests

These browser tests target retired Water UIs.
They remain available as historical evidence and are outside the active Playwright `testDir`.
Current browser checks live in `tests/browser/water-v102-*.spec.mjs` and the shared Water interaction checks.

The historical numerical sources and their Node tests remain in the repository.
Current release gates verify the supported V10.2 UI and shared scientific references.
Historical UI behavior must not block production compatibility redirects.
